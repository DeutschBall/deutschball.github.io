# 中炮巡河炮快攻龟背炮@2026.8.2

1、炮二平五 马8进7

2、马二进三 车9进1

3、车一平二 炮8退1

??? info "局面图"

	![](https://raw.githubusercontent.com/DeutschBall/picgo/main/20260802145007874.png)

至此形成中炮对龟背炮局面，黑退炮有平5平3平1三去向，俗称凤凰三点头。

在黑炮定位之前，红不可轻举妄动，例如走中炮盘头马等，因黑可炮8平5防御，红收效甚为。

4、炮八进二 ...

红此时炮八进二巡河针锋相对，逼迫黑冲边卒浪费步数或者平炮定位，依据黑平炮位置决定后续战术。

若黑挺边卒，推演如下：

??? question "卒9进1"

	4、... 卒9进1 

	黑挺边卒，只是防止打死车，再无其他目的，效率低下，相当于白让红走了炮八进二一步棋。
	
	如果硬要说好处，那就是比较矜持保持8路炮不定位。说好听了叫矜持，说难听了叫贻误战机。

	此时红巡河炮比较明显的打击点也是奇数路，平九打车，平七打象，平三打马。

	但是此时直接沿河十八大都是假先手，打了之后没有后续手段，反而黑棋冲卒拱炮遭到反制。

	**那么此时红棋应该如何形成后续手段呢？马八进七，腾出车九平八亮车捉炮的通道。接下来就可以巡河炮闪击抢一个先手，出车抓炮再抢先手。**

	黑抬起7路卒，给了红方挺七兵作为炮架然后进三兵邀兑的机会。

	如果黑方不管放任红方巡河炮兑兵，红炮打过来红方双马活跃，左车也可以顺利亮出，红优势。

	黑棋比较随手的应对方式是炮8平7，但是这样走黑平炮有且只有一个被动防守的目的，红棋就不会再冲三兵了，那么黑炮8平7就废掉了。
