1、炮八平五 炮2平5

2、炮二平三？ 马2进3

红方脱谱了，这步棋很差，理由如下：

??? note "推演分支"

    I、红二路炮本来起到封锁黑9路车的作用，擅离职守

    II、红八路车慢一步，黑可以抢出右直车

    III、红炮定位过早，黑方左马不会跳正了， 会跳边

    IV、红右马失去跳正的机会，进攻性不足

3、马八进七 车1平2

4、马二进一 马8进9

5、车一平二 车9平8

6、车九平八？

红方当时绝对脑子抽了，直接白送一个窝车，丢两先，中兵还要丢，被立上中炮。这一手是败着

??? info "局面图"

    ![image-20250817192529800](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250817192529800.png)

此时红方正手应该是车二进六前压，否则两个车均会被压制，那就不用下了。

6、 ... 车2进9

7、 马七退八 炮5进4

8、 士四进五 炮8进4

到此红方右侧车马炮被封锁，如同退守海岛，黑方可以闲庭信步出动两马做铁门栓。

9、 马八进七

当时不知道中炮应该退几步

??? info "局面图"

    ![image-20250817193134519](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250817193134519.png)

答案是退一步，因为可以给车留出沿河通道，并且可以冲中卒盘中马。

??? info "局面图"

    ![image-20250817193233669](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250817193233669.png)

9、 ... 炮5退1

10、 兵七进一 卒5进1？

当时不知道该走什么了，于是冲中卒，寻思给中炮生根，并且可以盘中马然后进3卒邀兑出象肩马。

然而这一步是臭棋。因为红马可以蹬3卒然后蹬中卒

为什么会犯这个错误呢？把中炮看得太重了，老是害怕红棋有马七进五兑中炮的棋。

此时黑方应该象3进5补厚中路，解放中炮，封锁住红方的沿河线，然后冲9卒活马徐图进展
