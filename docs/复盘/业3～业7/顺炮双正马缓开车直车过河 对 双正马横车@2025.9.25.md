1、炮二平五 炮8平5

2、马二进三 马8进7

3、马八进七 马2进3

4、兵七进一

??? note "推演分支"

    此时黑方最佳走法是出左直车骑河抓兵

    ??? info "局面图"

        ![image-20250928003748799](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250928003748799.png)

    推演如下：

    4、...车9平8

    5、车一进一 车8进5

    6、车一平六 车8平3

    7、马七进六 卒7进1

    8、相七进九 车3退1

    9、车九平七

    此时黑方面临关键抉择，此时正着是**士4进5**， 目的是给右车留出贴身车的位置， 面对两车见面的冲突而不为所动， 这步棋是有长远目光的

    ??? info "局面图"

        ![image-20250928005655451](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250928005655451.png)

    9、... 士4进5

    10、马六进七 车3进5

    11、相九退七 炮5平6！

    此时拆掉中炮显得非常灵动， 避免了马换炮，并且给右马生根，还腾出了飞象出贴身车的道路

    ??? info "局面图"

        ![image-20250928005947281](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250928005947281.png)

4、... 车9进1

5、车一平二 车9平4

6、车二进六

??? note "推演分支"

    红过河车接下来要平三杀卒压马

    ??? info "局面图"

        ![image-20250928010324655](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250928010324655.png)

    此时黑方最佳走法是卒7进1，目的是引诱红车回退杀卒，然后套炮打之。推演如下：

    6、... 卒7进1

    7、车二平三 炮5退1

    8、车三退一？ 炮5平7

    9、车三平八 炮2进5

    此时红只能车八退三吃炮，如果改走炮五平八，企图保留骑河车，会遭到更严重的利用：

    ??? info "局面图"

        ![image-20250928011202838](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250928011202838.png)

    10、炮五平八？ 卒3进1！

    如果车八进二则车1进2邀兑

    11、车八平七 车1进2！

    红车相当于给黑方当了清道夫， 两匹黑马蓄势待发， 红车有被围歼的风险
