4、炮八进二

红起巡河炮，目的是借助沿河十八打，迅速出动左侧车马。

??? xiang "rnbakabr1/9/1c4n2/p1p1p1p1p/7c1/1C7/P1P1P1P1P/4C1N2/9/RNBAKABR1 b - - 7 4"



??? note "推演分支"

    这里有一个陷阱，勾引黑炮8平3打底象抽车。推演如下：

    5、... 炮8平3

    6、车二进九！炮3进5

    7、帅五进一！炮7平9！

    8、车二平三！

    以上双方都带有强制性，而红车已经到位，巡河炮也随时可以平中叫将。黑方只有一个孤炮难以成事

    ??? xiang "rnbakaR2/9/1c4n2/p1p1p1p1p/9/1C7/P1P1P1P1P/4C1N2/4K4/cN1A1AB2 b - - 0 1"



    接下来红方可以炮八平五，士4进5，炮五平二，炮2平1，车三退一

    ??? xiang "r1b1ka3/4a1R2/c1n3n2/p1p1p1p1p/9/7C1/P1P1P1P1P/4C1N2/4K4/cN1A1AB2 b - - 0 1"



    接下来非常凶险：

    将5平6 兵三进一！

    此时挺三兵，看似远水不救近火，但是实际上红方也确实进攻乏力了，此时走随手棋炮二进五就没机会了。

    ??? xiang "r1bk1a3/4a1R2/c1n3n2/p1p1p1p1p/9/6PC1/P1P1P3P/4C1N2/4K4/cN1A1AB2 b - - 0 1"



    车1平2 马八进六！车2进8！ 炮五平六！

    解杀还杀的好棋，螳臂却挡车，黑方也陷入了单车寡炮进攻乏力之地，而红中炮平六后反而立上了炮架，此后三路马借炮使马！
