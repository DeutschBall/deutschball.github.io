快一个月没下棋，水平显著下降，具体表现为被业5爆超🥵🥵🥵

必须从胯下之辱中吸取经验(

1、炮二平五 炮8平5

2、马二进三 马8进7

3、车一平二 车9进1

4、兵三进一 马2进3

5、马八进七 车9平4

到此都是谱招，正常继续下去可以形成 顺炮直车对横车 - 红两头蛇对黑双横车

然而红方在此开始脱谱

6、炮八进二？

??? info "局面图"

    ![image-20250809184719269](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250809184719269.png)

红方走这个巡河炮很牵强，他只有两个打击点位，要么平七打马，要么平九打车。

然而平九打车黑方正好出右直车躲开，这是帮助黑方走棋。

那么为了应对炮八平七打马，黑方很显然地可以走卒3进1，本来红方如果不走两头蛇，黑方也是要挺3卒的，一点毛病都没有。

??? note "若黑走骑河车抓炮，推演："

    6、... 车4进4

    7、炮八平七 马3退5！

    此时一定不能走车4平7对抓，因为红可以马三进二，如此黑方只能马3退5，红车九平八抓炮有先手，相三进一抓车也有先手。

    8、车九平八

    此时黑方有两种走法，一是车1平2保炮，二是卒3进1对抓炮

    走哪个好呢？显然不能走车1平2

    ??? info "局面图"

        ![image-20250809190111971](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250809190111971.png)

    首先车1平2直接就被拴住无根车炮了，接下来红车八进五骑河，黑直接失去了冲3卒反击的机会

    ??? info "局面图"

        ![image-20250809190322118](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250809190322118.png)

    走卒3进1对抓炮，黑车卒还可以威胁红七路马，更好。

??? note "对局时黑挺3卒"

    6、... 卒3进1

    7、炮八平九？ 车1平2

    8、车九平八 炮2进4

    9、车二进六？

    红方也真是心大，这炮打中兵就要兑窝车，红方起码要丢一先手吧，这还有功夫右车过来压马啊？

    此时黑方眼见可以炮2平5立刻得利，兑掉窝车让红方丢一先手。

    然而复盘分析，软件给出了**车4进6**这一更狠毒的招法。

    ??? info "局面图"

        ![image-20250809191532437](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250809191532437.png)

    车4进6，放着眼前利益不占，是瞄准了更大的利益，此着目的是杀掉红左马，导致红左车脱根，这样再打将就能狠狠地抽车。

    如果红马三退五窝心则黑炮5进4狠狠按住，接下来可以霸王车躲士。红就等死完了。

    如果黑方真的走出这手棋来，红方当时就得丢一匹马，这个战果是要大于兑窝车让红方丢一先的。红方也防不住这手了。

    并且这个丢马是连带着丢势的，红方并没有反击. 红等死就完了

    ??? info "局面图"

        ![image-20250809191741642](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250809191741642.png)

    9、... 炮8平5

    10、马三进五 车2进9

    11、马七退八 炮5进4

    到此黑方已经取得了巨大优势，黑方成功架上了中炮，逼退了红马。

    然而当时我拔剑四顾心茫然，不知道接下来该走啥了。

    当时鼠目寸光看到了两步棋，

    一是冲中卒，目的是当红车二平三压马，黑方可以盘中马

    二是卒1进1，这是纯粹恶趣味戳戳炮，实际上帮红方走棋了，他那个逼炮就在那旮旯里藏着就挺好。

    ??? info "局面图"

        ![image-20250809192630867](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250809192630867.png)

    然而我就是没忍住走了戳戳炮，性情中人，爽了再说。结果红方可以炮九平五反将一军，我把先手丢了🤣👉🤡。

    那么此时黑方冲中卒行吗？也不行，实际上我看到了这一点，时间不够了没想到第三个法，仓促走了戳戳炮😅😅😅。

    卒5进1，马八进七！炮5退1，兵七进一！到此红方大优了，黑方中路过于薄弱，红方开始反攻倒算。

    ??? info "局面图"

        ![image-20250809193159434](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250809193159434.png)

    那么此时黑方应该走什么呢？

    接下来红方眼见有两个打击目标，一是马八进七蹬炮，二是车二平三抓马。

    ??? info "局面图"

        ![image-20250809193514042](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250809193514042.png)

    黑方能否放弃7路马强攻？时机未到，红方将门有车守护，黑方做不了铁门栓。

    那么黑方只能考虑一步棋解决两个弱点。

    如果红车二平三，黑如果能炮5平7倒打车就爽了，但是黑方中路薄弱，因此需要先补象。

    因此这招棋就是**象7进5**

    ??? info "局面图"

        ![image-20250809193904520](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250809193904520.png)

    接下来红方如果马八进七，则黑车4进6

    红方如果车二平三，则黑炮5平7，车三平四

    这里有一个疑问，黑方中炮离开，值不值。或者说，黑方中炮离开后，接下来应该如何进展？

    此时黑方眼见有马7进8蹬车，车4进5抢占兵线两个走法，软件给出了车4进4骑河的走法。

    ??? info "局面图"

        ![image-20250809194329280](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250809194329280.png)

    这眼见的两个走法行不行呢？

    ??? note "推演分支"

        马7进8是我经常会犯的一个错误，**红三兵他是个活物啊**，他不是个砖头啊，他兵三进一我不就炸了吗。推演如下

        马7进8，兵三进一，马8进9

        ??? info "局面图"

            ![image-20250809194810879](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250809194810879.png)

        这里红方看上去也可以炮九平二然后下底，但是黑可以车4平8拦截，如果此时黑9路马离开，则红可以炮二进一交给三兵看守，接下来可以炮五平二打车。因此这说明红平炮下底时机未到，应先引离黑9路马。

        ??? info "局面图"

            ![image-20250809194916174](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250809194916174.png)

        车四退三！马9进8，炮九平二！

        此时时机就对了，红炮可以交给三兵保管了

        ??? info "局面图"

            ![image-20250809195121621](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250809195121621.png)

    车4进5是可以走的，目的是抢占兵线，防止红车四退三守护兵线，并且压制红马。

    接下来红兵三进一，进攻黑7路马，黑可马3进4蹬车，然后炮7平3，接下来过3卒围攻红方边炮

    软件给出车4进4骑河更加强硬，此时摸摸红边炮，🧐已经没有生命特征💀💀💀，接下来冲1卒直接把小炮戳爆了
