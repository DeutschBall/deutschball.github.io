4、士六进五 车1平4

然而红方当时走了士六进五，在另一个局面“顺炮直车对横车 - 红两头蛇对黑双横车”中，红方确实有补士待机的走法。

但是此时红左马未启，两兵也没冲，就先补士，有臭棋乱补士的嫌疑

针对红方这步补士，我当时立刻走了车9平4，目的一是控制红帅门，二是如果红方不查可以走兵团大战的棋谱。

??? info "局面图"

    ![image-20250612234816418](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250612234816418.png)

然而这里红方可以走五六炮挡住黑车，因此此时黑方横车占肋并没有什么便宜。

红方补士相当于浪费了一步棋，但是也避免了可能的打中兵叫将的先手，那么黑方在之后就不应该再考虑打中兵抢先手的手段。此时黑方并没有明显的反击方式，应该正常出动子力，比如右正马，反正红方补士是缓了一步棋的。

5、炮八平六 马2进3

6、兵七进一 ...

这种局面很熟悉，黑方有炮压马的手段，到底应不应该压马呢？压马之后黑方还有什么后续手段呢？

??? info "局面图"

    ![image-20250612235311234](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250612235311234.png)

由于红方过早地补了中士，因此红右车一时半会儿是无法支援左翼的，那么此时黑炮压马，红方是没有任何手段驱赶黑炮的，因此黑方应该大胆炮压马

??? info "局面图"

    ![image-20250612235452010](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250612235452010.png)

**炮压马之后，黑方的后续手段是什么？**

那就是红七相。由于红方也是中炮，因此红七相此时是个孤儿，黑肋车两步就可以威胁到红七相。

??? info "局面图"

    ![image-20250612235627935](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250612235627935.png)

并且黑方有了出右直车的权利，右直车看炮，闪炮可以闪击红左马。

并且直接封锁了红左侧车马，红左侧子力瘫痪。

**红方针对黑方炮压马有什么反击呢？**

此时黑方的唯一弱点就是，右炮走后，左马脱根，红右车可以进到卒林压马。

??? info "局面图"

    ![image-20250612235849298](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250612235849298.png)

但是黑方并不害怕

右马退窝心给左马生根即可

??? info "局面图"

    ![image-20250613000046457](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250613000046457.png)

7、马八进七 ...

很明显，接下来红方可以出左直车，也可以右车巡河然后跳马打车。

??? info "局面图"

    ![image-20250613000330664](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250613000330664.png)

此时黑方应该先管哪个事呢？

应该先遏制红出左直车，因为红巡河车跳马打车需要先右车巡河，此时黑再处理也来得及。

此时黑方应走炮2平1率先亮右直车，如此红左车还是开不出来。

7、马八进七 卒7进1

此局面下红方很显然地有两步棋可以走，车二进四或者车九平八，这两步棋好不好呢？

??? info "局面图"

    ![image-20250613000838968](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250613000838968.png)

应该说都差强人意，但是也没有第三种走法了。

车九平八，则黑炮2进4，随时炮2平7瞄闷宫相，红方右车不敢乱动，左车也被压制，黑方优势

??? info "局面图"

    ![image-20250613001034036](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250613001034036.png)

车二进四，准备上马打车

然而由于黑已经挺起7卒，因此马7进6抢占河口，红方连上马的权利都没有

??? info "局面图"

    ![image-20250613001155043](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250613001155043.png)

那么接下来红方应该怎么走呢？红方比较明显的想法是邀兑三兵活马，

但是红直接冲三兵则黑炮2进2，红不敢继续冲三兵，因为黑炮2平7是瞄着闷宫相的。

因此红方可以先车九平八拉住黑右侧车炮，黑只能炮2进4前压，否则让红车八进六压马就被动了。此时黑方就没有巡河炮的手段了，此时红方可以邀兑三兵。

此时黑方应该立刻车4进5准备平3压马，双车集中于红方左翼发动攻势。
