??? note "复盘分析"

    1、炮二平五 马8进9

    到此是纯dna开局，形成**中炮过河车互进七兵对屏风马**局面

    接下来黑方有多种选择，主流的是平炮兑车和左马盘河两种。

    然而对局中黑方选择了象3进5

    ??? info "局面图"

        ![image-20250509194608626](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250509194608626.png)

    5、兵七进一 象3进5

    ??? info "局面图"

        ![image-20250509194845725](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250509194845725.png)

    黑方补中象， 看似让黑左马脱根， 当时我没敢车二平三捉马， 我害怕黑方直接弃马，炮2进4然后平7打兵打车，我会很被动

    推演如下：

    ??? note "推演分支"

        6、车二平三 炮2进4

        7、车三进一？ 炮2平7！

        如此黑方在红右翼有攻势，红方被动。

        ??? info "局面图"

            ![image-20250509195725619](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250509195725619.png)

        虽然第7回合红方可以兵三进一防止黑炮2平7， 但是要么松开了黑左马退，要么放7卒过河。

        黑方有还手之力，夜长梦多。

    因此， 基于上述考虑， 如果平车压马， 黑方会有反击。

    因此我没有着急车二平三。

    6、马八进七 士4进5

    眼见黑方要出贴身车， 我当时就想，能不能给他憋回去，不让他出来？

    ??? info "局面图"

        ![image-20250509200055329](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250509200055329.png)

    我想左马盘河然后左炮巡河给马生根， 然后拆掉中炮套在马后面打车

    然而这三步棋的先后顺序很重要

    如果先走马七进六， 黑方不会傻傻出车等着被打， 而是先冲3卒破坏红河口阵地结构。推演如下：

    ??? note "推演分支"

        7、马七进六  卒3进1

        8、兵三进一 车一平四

        黑方以弃3卒的代价，成功开出右贴身车，并且接下来会用贴身车反击红方。

        夜长梦多

    而先升巡河炮，就不会有上述问题， 并且巡河炮目的更多， 可以建立河口阵地，可以邀兑三兵活通右马， 也防止了黑炮2进4反击，

    ??? info "局面图"

        ![image-20250509200630004](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250509200630004.png)

    7、炮八进二

    接下来红可以车二平三压马了， 黑只有一步棋可以走，炮2进1， 然后冲3卒打车反击

    ??? info "局面图"

        ![image-20250509202757951](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250509202757951.png)

    然而对手没走出来

    7、炮八进二 卒3进1？

    黑棋的目的，应该还是想破坏红河口阵地，继续出贴身车

    然而红兵七进一，黑方必须得飞高象，否则红继续冲兵，黑就要崩溃

    那么黑飞高象，就守不住7兵和7马，此时正是红车压马的最佳时机

    8、兵七进一 象5进3

    9、车二平三 马3进4！

    ??? info "局面图"

        ![image-20250509204235621](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250509204235621.png)

    黑高象还不敢落回去。落回去马没了。

    由于黑高象不敢落，接下来红车三退一然后炮八平三，对黑7马和底象施加巨大压力。

    此时黑方不应该再保7马了， 应该弃掉7马，等红车吃马，再落象，接着打车的先手抢出右车，寻求反击。

    推演如下：

    ??? note "推演分支"

        9、车二平三 马3进2

        10、车三进一 象3退5

        11、车三退一 车1平3

        ??? info "局面图"

            ![image-20250509210206480](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250509210206480.png)

        12、车九进二 车3进6

        13、炮八退三 马4进2！

        14、炮八平七 马2进1

        15、炮七进二 马1退3

        黑方得回失子， 双方均势

        ??? info "局面图"

            ![image-20250509210410358](https://raw.githubusercontent.com/DeutschBall/picbed/main/image-20250509210410358.png)

    对局时并没有考虑这么深， 但是确实想到了黑方会落象打我的车， 躲车就很难受， 因此我也没有吃马

    当时想走车三退一，但是考虑到黑马4进6然后象3退5还可能有反击， 于是改走兵三进一， 防止黑马4进6踩双。

    接下来如果黑卒7进1， 则红车可以放心杀马，等黑方落象时再车三退三杀卒巡河，红方稳优
