# 顺炮直车两头蛇对双横车@2026.11.4

每次走到这个局面，再往后的棋谱没推演过了，开始乱走，于是今天着重推演一下这个谱。

这个谱还有中炮过河车对屏风马-红左马盘河对黑骑河车，这两个谱我总有一种莫名的爽感。特别有高人对决的感觉。

2、马二进三 马8进7

3、车一平二 车9进1

4、马八进七 车9平4

5、兵三进一 马2进3

6、兵七进一 车1进1

    ![](https://raw.githubusercontent.com/DeutschBall/picgo/main/20261104221651815.png)

到此形成DNA阵势。接下来如果红棋走炮八进二或者补士，黑棋可以走叶底藏花。

今天推演一下红棋其他走法。

## 马三进四

7、马三进四 车4进7

8、炮八进二

此时黑棋有个骗着，车1平6抓马，引诱炮五平四打车。

??? question "车1平6"

此时黑棋正着卒3进1，妙手，拆掉红棋河口阵地，获得车1平6抓马的先手快速出车。

遇到河口炮借兵为炮架时可以考虑送卒引离兵，拆掉炮架。

12、炮八平五 车6平3

给马流出马七进八的路线。

??? failure "为什么不能炮八平七？"

    时刻注意炮或者车赛高象眼的手段。

感觉红棋相对好走。

## 相七进九

7、相七进九

??? info "局面图"

    ![](https://raw.githubusercontent.com/DeutschBall/picgo/main/20261104233226339.png)

此时比较明显的有车4进3、5、7。但是都不理想，不如卒1进1。

车4进3明显有马三进四蹬，自不必多提。

车4进5也可以蹬，貌似能车4平3压马，但实际上是自投罗网。

车4进7只能抠马，但是红可以车九平七轻松化解。

车4进5这路变化可以推演一下：

??? question "车4进5"

    7、... 车4进5

    8、马三进四 车4平3

    9、车九平七 卒3进1

    10、炮五平三

    ??? info "局面图"

        ![](https://raw.githubusercontent.com/DeutschBall/picgo/main/20261104234449793.png)

    要求打死车。

    此时黑棋已经是骑虎难下了，有的人可能会害怕被打死车，走车3平2躲开，那么红棋兵七进一马上就要压马，大优。

    此时黑棋只能放手一搏了。

    10、... 卒3进1

    11、炮三进一 车1平6

    12、马四退五！

    巧妙的运马，保持对黑车的攻击。如果走马四进三则车6进5解围。

    12、... 炮5进4

    13、马五进七 炮5退2

    ??? info "局面图"

        ![](https://raw.githubusercontent.com/DeutschBall/picgo/main/20261104235717192.png)

    接下来黑车6进5要捉双并且抽将。但是红棋不用太害怕，不会丢车，顶多丢个炮。

    14、前马进九 炮2进4

    此时如果下车来抽，顶多抽个炮，红棋中防就补好了。黑无力回天。

    15、车二进五

    准备随时弃车杀炮解围，甚至可以直接杀炮，还多着一个大子。

    ??? info "局面图"

        ![](https://raw.githubusercontent.com/DeutschBall/picgo/main/20261105000221279.png)

7、... 卒1进1

此时红棋有两个走法，要么士六进五，要么车二进五。

区别在于车二进五更加主动，后面可以搭配马三进四，再马四进六或者车二平六兑车。

??? question "红先补士"

    8、士六进五 卒1进1

    9、兵九进一 车1进4

    ??? info "局面图"

        ![](https://raw.githubusercontent.com/DeutschBall/picgo/main/20261105000425361.png)

    此时会有人走炮八退一企图打死车，但是黑有炮2进4卡象眼杀七兵。或者车1退1躲开。

    10、车二进五 炮2平1

    也有黑棋走车4进7的，直接车九平六兑掉即可。

    11、炮八退一 车4平1

    黑棋卯足了劲在1路上狠狠地冲。

    此时红棋再走炮八平九打不到车，黑可以前车平3躲开了，炮拉着相飞不起来。

    12、马三进四 炮1进5

    13、马七退六！

    ??? info "局面图"

        ![](https://raw.githubusercontent.com/DeutschBall/picgo/main/20261105002254055.png)

    关键的一着，避开黑棋锋芒，如果兑炮则黑保留一个边车对红左翼有骚扰。

??? question "红先骑河车"

    8、车二进五 卒1进1

    9、兵九进一 车1进4

    10、马三进四 炮2平1

    11、车二平六 车4平2

    ??? info "局面图"
