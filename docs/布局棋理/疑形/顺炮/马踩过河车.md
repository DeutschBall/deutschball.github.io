# 马踩过河车@2026.6.27

## 典型局面

??? info "局面图"

    ![](https://raw.githubusercontent.com/DeutschBall/picgo/main/20260627170548495.png)

此时红右马跃出踩车，勾引黑平车压马，而后红左侧马窝心勾引黑打炮，右侧先锋马踩双换炮后窝心马从另一侧绕出。

## 局例

### 局例-顺炮直车进三兵对横车平肋过河

1、炮二平五 炮8平5

2、马二进三 马8进7

3、车一平二 车9进1

4、马八进七 车9平4

5、兵三进一 车4进5

6、马三进四 车4平3

7、马七退五 炮5进4

8、马四进六

??? info "局面图"

    ![](https://raw.githubusercontent.com/DeutschBall/picgo/main/20260627170855621.png)

黑车被踩，来不及架双中炮，必须躲车，红棋能抢到窝心马跳出。

8、... 车3平4

9、马六退五 车4平5

10、马五进七 车5退1

11、炮八退一

??? info "局面图"

    ![](https://raw.githubusercontent.com/DeutschBall/picgo/main/20260627171302747.png)

红棋接下来可以走雷公炮盘头马，如果红棋用马换掉黑另一个炮，那么红方双车炮对黑方双车马，显然双车炮威力更大速度更快。
