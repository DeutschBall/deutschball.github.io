# 退中炮平炮打过河车@2026.6.27

## 典型局面

??? info "局面图"

    ![](https://raw.githubusercontent.com/DeutschBall/picgo/main/20260802170231668.png)

如图是顺炮直车过河对横车经典牢谱形成的局面。

黑方实际上不怕车压马，反而是可以利用红方过河车出子布阵。

就算是黑棋跳双正马，炮也可以暗保马，不怕红车吃马。

黑跳双正马后可以退中炮借马形成新炮架，然后平炮打车反击。

这个车孤军深入可能遭到多种打击，比如马踩，退炮打，或者车保住马然后用炮打死。
