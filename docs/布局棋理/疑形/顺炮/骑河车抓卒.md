# 骑河车抓卒@2026.6.27

## 典型局面

??? info "局面图"

    ![](https://raw.githubusercontent.com/DeutschBall/picgo/main/20260610225718296.png)

顺炮直车对横车进3卒。

衍生局面有顺炮直车对横车边马进3卒/正马进3卒 等等

这个局面下黑棋3卒面临红右车骑河抓死的威胁。

此时黑横车还没有定位，红不急于骑河车抓卒，可以等黑车9平4定位后，再走车二进五骑河抓。

    ![](https://raw.githubusercontent.com/DeutschBall/picgo/main/20261103214128927.png)

此时黑飞边象红有明显的炮八进四。

黑棋稳妥走法是炮5平6再补象给马生根。但是拆炮丢一先。

黑棋如果走卒5进1，试图搅乱局势。红棋简明炮打中卒即可。如果黑盘头马，红只需进中兵保持压力即可。
