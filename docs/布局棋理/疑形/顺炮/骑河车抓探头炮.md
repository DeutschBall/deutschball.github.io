# 骑河车抓探头炮@2026.6.27

## 典型局面

??? info "典型局面-红双正马探头炮"

    ??? xiang "rnbakab2/9/1c2c1n2/p1p1p1p1p/9/1C1r5/P1P1P1P1P/2N1C1N2/9/R1BAKABR1 w - - 10 6"

??? info "典型局面-红单提马探头炮"

首先说红探头炮的目的。黑棋右马无法跳正，黑棋进3卒则红棋先平炮打车然后骑河车抓黑3卒。

??? xiang "r1bakab2/3r5/nc2c1n2/p3p1p1p/2p4R1/C8/P1P1P1P1P/2N1C1N2/9/R1BAKAB2 b - - 0 1"



借助巡河炮平七平九骚扰的先手，红棋想率先出动九路车。

然而上述两个局面红探头炮均没有稳定的立足之地，被黑骑河车拦截后会非常尴尬，面临被卒拱死的风险。

不管红炮八平七还是平九还是进兵交给马保，均无法善终。

此时红有炮八平七和平九两个选择，黑棋均象3进1应对。

目的一是腾开拐角马路线，此后红出九路车抓炮时黑正好拐角马保炮。二是让红炮没有兑换的目标，如果跳边马红炮走投无路可以换马，而飞边象黑炮顶多能换象。
