# 贪冲卒大子慢被压马@2026.6.14

## 典型局面

??? xiang "rnbakab1r/9/4c1nc1/p1p1p1p1p/9/9/P1P1P1P1P/1C2C1N2/9/RNBAKABR1 b - - 5 3"



此局面下黑棋仗着自己有担子炮，想不出车，先贪一个卒。

不管黑棋冲哪个卒，红车二进六压马黑棋就不好办。

## 局例

### 局例-中炮对小列炮进7卒

1、炮二平五 炮2平5

2、马二进三 马8进7

3、车一平二 卒7进1？

??? xiang "rnbakab1r/9/4c1nc1/p1p1p3p/6p2/9/P1P1P1P1P/1C2C1N2/9/RNBAKABR1 w - - 0 4"



黑进7卒不仅起不到活通7路马的作用，并且会被红右车过河把7路马逼退后，红棋还能抢到兵七进一，如此黑棋两马都死。

红棋是一定能抢到兵七进一的，这一步制约黑3路马很关键。

4、车二进六 马2进3？

5、车二平三 马7退5

黑棋若走马3退5则炮八进五入侵布置线，黑棋崩溃

此时红棋的后续手段是什么呢？

黑棋有窝心马，炮震五子是最具针对性的走法，直接走五八炮，黑棋可以冲3卒，因此红棋先挺七兵顺便制马，如此黑棋两马非常痛苦。

6、兵七进一 车1平2

7、马八进七 车2进6

8、车九进二！

红高车保马，黑过河车就不足为惧了。

8、车二平三

9、炮八进四 卒3进1

10、炮八平七

明显红大优。

如果黑棋在第4回合改走高车保马呢？

4、 ... 车9进2

此时红棋又该如何考虑呢？

黑棋2路马只能跳正，如果跳边红棋有炮八进五入侵布置线得子。

因此红棋走兵七进一，黑棋明知道跳正马被制也得这样走。

红棋不怕黑马7进6再冲7卒的反击，黑中卒无根，红中炮打出后车二平三叫铁门栓有先手。

5、兵七进一 马2进3

6、马八进七 车1平2

7、车九平八 车2进6

红棋先马七进六盘河了，接下来就要兵七进一反击，黑7路马也上不来，红优。

### 局例-红棋不出车勾引黑棋犯错

1、炮二平五 炮2平5

2、马二进三 马8进7

3、兵七进一

??? xiang "rnbakab1r/9/4c1nc1/p1p1p1p1p/9/2P6/P3P1P1P/1C2C1N2/9/RNBAKAB1R b - - 0 3"



红棋不出车，先挺七兵勾引黑对挺7卒，黑棋挺卒后红再车一平二，黑方就相当于落入贪了一步卒的陷阱，红棋就相当于抢到了兵七进一这关键一步。

黑棋只能走车9平8，如此红棋再出车黑棋就可以进炮封车了。

黑棋出车红棋可以抢两头蛇，或者马八进七出左车也来个前炮后车封车。
